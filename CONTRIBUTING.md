# Contributing

Thanks for helping build GnuCash.DotNet.

The canonical contributor guide is [How to Contribute.md](How%20to%20Contribute.md). This short file exists because GitHub automatically surfaces `CONTRIBUTING.md` when people open issues or pull requests.

Before opening a pull request:

1. Keep changes scoped to one coherent behavior or structure update.
2. Run `pwsh -File .\tools\check.ps1`.
3. Update `gnucash-dotnet-docs/` when architecture, bridge behavior, packaging, or release behavior changes.
4. Do not commit GnuCash binaries or copied upstream source into this repository.
